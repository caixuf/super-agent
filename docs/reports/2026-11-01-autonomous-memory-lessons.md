# 自动记忆闭环：修复经验与验证纪律

日期：2026-11-01。范围：P1 自动准入实现与隔离测试；不是生产上线证明。
执行与验收记录见 `docs/handoff/2026-11-01-autonomous-memory.md`。

## 1. 原文引用不是用户确认，更不是真值

模型必须提供用户原文锚点，但精确子串仍可能丢掉否定和限定：

- 原句“以后可能采用某门限，但还没确定”，不能只摘“采用某门限”写成决定。
- “不能把某建议当成我的决定”不能被反向提取为偏好。
- 混合回合“是否改用英文？以后默认中文回复。”不能整轮丢弃，亦不能把问句当事实。

处理方式：先保留用户引句，结合其完整句上下文审查；不确定、外部转述与未证实结论隔离。精确排除“尽可能”这种表达要求的词组，不能因为句子含“以后”就放行真正的“可能”。主题、代际、标签与置信度不能直接信任模型输出。

技术执行结论另需受信宿主回执，至少绑定当前事件与语句摘要并声明成功；普通偏好不需要伪造执行回执。正常偏好准入无人工审批必经步骤，外部资料学习的人工审核规则不因此取消。

## 2. 先隔离候选，验证通过后原子激活

“写入成功”和“任务成功”不是同一件事。后台索引已排队不代表索引已持久化；返回任意召回结果也不代表本条事实可用。

自动路径采用：候选行 → 单事实同步索引与身份校验 → 冲突裁决 → 事务内激活/旧事实替换/准确事实召回验证 → 提交。回读失败需整体回滚，保留旧事实 active，新事实仍为 candidate；不能只返回错误却留下已激活的新事实。月度报告不得提前发布候选正文。

兼容性教训：不要全局关闭候选后台索引。已有人工/受信资料发布链路仍依赖它；仅自动准入调用显式选择同步索引，保留旧接口默认行为。

## 3. 冲突裁决不能靠最新八条或字面相似度兜底

“以后回答保持简洁”与“今后回答尽可能详细”字面相似度很低，却可能约束同一件事；主题若直接取完整语句前缀也不相同。旧事实较早时，仅查最新八条还会直接漏掉它。

自动路径使用有界、按身份与代际过滤的候选扫描，复用既有冲突裁决，并对有主题线索的候选启用保守模式。模型不可用、非法结果、预算不足都应 defer，不能默认 coexist。语义重复是成功去重，不应反复失败；验证重复时用旧事实自身的内容与主题，而不是新措辞。

裁决在数据库事务外执行以免长时间持写锁；提交前必须复核 active 快照。裁决期间出现新事实，旧裁决回滚重试。扫描预算、候选个数与时间预算应分别说明；当前 10 秒是调度软预算，单次调用仍受既有 30 秒 provider 上界，不是端到端硬截止保证。

## 4. 私有自动事实与团队共享事实是两类授权

事件幂等身份须包含 profile/user/agent/session/turn。读取保护需贯穿 store、prefetch 和 L1/L2/L3，不是只在写入时加标签。

团队共享入口应同时允许：同团队已有共享资料，以及本 agent/profile 自己的自动事实；不能无条件加严格过滤而打断团队共享，也不能一律排除自动来源而让本人永远召回不到新记忆。自动事实不能被同团队其他身份读取。相关开关由受信宿主绑定，不由对话中的参数指定。

## 5. 重试需要冻结提取、准确审计和坏样本隔离

提取结果按事件与策略冻结，并绑定正文摘要和身份摘要。否则重试时模型改写候选会改变事实身份，破坏幂等。冻结文件需要私有权限、不可覆盖和原子落盘；凭据候选先拒绝/脱敏，不能进入正文归档、普通日志和报告。审计只保留必要摘要与固定原因码，并分别保留首次与最终决定。

坏 spool 记录隔离后应继续处理后面的有效记录。模型、索引等暂时故障保留有界退避，不无限重试，不把故障包装成 no_match 或成功。

## 6. 测试要验证行为，不能因注入点过时而假绿

实现把召回验证迁入激活事务后，继续 mock 旧 pipeline 私有方法不会制造真实回读失败。新参数也可能令旧 mock 签名抛异常，使“未写入”断言误通过。

独立测试应同时断言：

1. 真实故障入口被执行，并得到准确固定原因码。
2. 新事实未激活；有旧事实时旧事实仍 active。
3. 冲突 judge 确实看到了目标旧事实，不能仅检查 written=0。
4. 正例与反例成对覆盖：本人可读/外人不可读、明确决定可记/不确定不记。

隔离测试还要显式注入知识源。实体金标曾自动读取宿主 MEMORY.md，影响召回排序；用同一份空合成知识文件对照基线与当前树后，二者均通过，不能为此放松金标断言。跳过的宿主/可选依赖测试不能计为通过。

## 7. 离线质量指标不能冒充线上智能提升

`python3 tools/memory_autonomy_eval.py --offline` 使用固定合成样本、确定性嵌入和 synthetic conflict reviewer。它检验安全门与写入/索引/召回链路；准确命中应核对本样本的 fact_id 与语句，不能由别的记忆代偿。

当前固定十项样本通过不代表真实模型抽取精度已被证明。真实模型调用数为零，成本不可测量；模拟裁决次数单列。后续仍需真实模型合成金标、宿主接线验证、可回退灰度与持续质量监测。未经这些阶段，不宣称线上全自动闭环或持续自优化已经完成。历史积压不能直接灌库。

## 8. 本次证据与后续边界

完整合成环境全仓复跑：2083 passed / 46 skipped / 296.95s；最后测试准备屏障落盘后的独立前序＋专项＋门禁：102 passed / 10.75s。某冲突用例曾在全仓提前退出但独跑及组合未复现；补完整 outcome、准确 reason 和准备屏障，不宣称未证实的索引竞态已被修复。详见同日 handoff 的历史失败与调查记录。

远端有并行新提交时，脏工作区不要为了 push 强推、整仓暂存或 stash/reset 用户改动。本轮精确文件归档在独立 feature 分支，后续合并最新主线须重新做集成验证。
