> 记法：**厂商产品**（托管，改名很快）与**框架/插件**（可自托管，能拿来对照架构）分开列。

## 3. 反复出现、值得抄的机制（跨项目收敛出来的）

1. **主管制（一句话拉起班子）**：用户只跟一个"主管"对话，由它创建/配置其他 Bot 与群聊 —— 同时是**降 token 手段**（群聊只让管理员回话）。
2. **一 Bot = 一 session + 独立记忆**：人格、上下文、模型各自独立；记忆用**纯文本文件**存（可 diff、可迁移、可人读）。
3. **记忆要有人管**：每轮结束做一次**记忆审查**（该存/该改/该删），而不是只追加。
4. **用量按 Bot 归属**：谁花的钱按"发起人/Bot/模型"三个维度可查 —— 多 Bot 共用算力时这是必需的账本。
5. **隔离边界分层**：跨用户硬件级隔离；账号内按账号共享算力、按 Bot 隔离人格与工作区。
6. **派工也要进审查面**：自动化写入与 delegation 与 shell 同级接受审批；审批只管"将执行的动作"，**不能回滚已发生的副作用**。
7. **每个 Bot 同一时刻只跑一个 computer-use 任务**（屏幕是独占资源）。

## 4. 本仓的差异面（别人没有或很少做的）

- 对**智能体自身**的机械可证验证面：身份注入点逐字节等式、请求转储取证、干净室复验；
- 通用仓**零业务词门禁**（词表 + 结构性断言 + 逐字节等式，而不是靠人自觉）；
- 记忆的**代际硬隔离**与突触强化/衰减（不是单纯追加）。
