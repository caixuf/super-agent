# T4 触发建议与运行时钩子回执

日期：2026-10-26。范围：判断图文是否有助理解，并通过现有生命周期注入临时建议。

## 实现

- `agentcore/document_intent.py`：可解释建议器，返回artifact / inline / defer、任务族、原因和是否避免重建整篇。
- `plugins/illustrated_delivery/`：默认关闭的pre_llm_call插件，只返回context。
- `tests/test_document_intent.py`、`tests/test_illustrated_delivery.py`：请求、结构和真实注册回归。

建议器覆盖架构关系、多阶段计划、机制流程、方案取舍；尊重明确文字偏好，状态/定义直接回答，局部追问不自动重建。可输入planned_structure中的角色、关系、阶段、步骤、备选项和评价维度。未知请求交给模型按回答结构判断，不以词表未命中作为否决。

运行时pre-call阶段尚未拿到模型的回答提纲，因此此时是规则提示加语义政策，而不是已经完成任意语义分类。最终是否调用技能由模型决定。建议明确要求讲人话、先结论、解释角色动作和首次术语；文件名/API/内部标识仅在帮助核对时出现。图必须改善理解，不强制装饰或长文化。

## 接口核对与隔离验证

核对现场源码：Hermes `agent/turn_context.py::_collect_pre_llm_call_context` 传user_message、conversation_history、parent_session_id等；返回context进入临时用户上下文，不注册系统提示词段。`PluginContext.register_hook`为公开接口。

最终命令：

```bash
python3 -m pytest tests/test_document_intent.py tests/test_illustrated_delivery.py tests/test_repo_neutrality.py -q
```

结果：**59 passed in 13.42s**，包含中立门禁13项与真实Hermes注册/调用，无跳过。真实注册测试用Hermes自己的`.venv/bin/python`，设置临时HERMES_HOME，不插入本体仓到sys.path，验证管理员engine_root可加载唯一源码。

发现并处理的现场差异：系统Python没有ruamel，Hermes Python没有安装agentcore。插件延迟导入，只有enabled=true才需要引擎；管理员engine_root提供明确源码位置，避免全局安装依赖或复制一份引擎。

## 最小启用步骤（本切片未执行）

1. 将插件目录安装到目标profile的plugins/illustrated-delivery，保留原目录与配置。
2. 使用实际Hermes运行时解释器，明确HERMES_HOME；源码目录仅用于加载Hermes公开管理API。
3. 通过 `hermes_cli.plugins_state.save_plugin_setting('illustrated-delivery', ('enabled',), True)` 与 `('engine_root',)` 设置插件自身键，不整文件覆盖配置。
4. 调用 `hermes_cli.plugins_cmd.cmd_enable('illustrated-delivery')`，它保留已有allow-list并调用公开activation。无新capabilities、无tool override。
5. 若插件已enabled但设置改变，调用 `hermes_cli.plugins_activation.activate_plugin_now('illustrated-delivery', in_process=False)`。检查gateway_reloaded与activation hooks，不把restart_required当成功。

源码证据：`plugins_activation.py::activate_plugin_now`通过control socket请求gateway的`reload-plugins`；`gateway/run_plugin_rewire.py`处理请求；hooks装载后即可使用，Python工具和系统提示词才延至新会话。本插件两者均未注册。

## 最终冻结回执

源码、manifest、README、两份测试和本报告均已落盘。最后针对性验证为 **59 passed in 0.88s**，其中触发与hook为46项，中立门禁13项。

真实hook调用核对过的payload：`session_id, task_id, turn_id, user_message, conversation_history, is_first_turn, model, platform, parent_session_id, sender_id`。回调以明确user_message/conversation_history/parent_session_id及`**kwargs`兼容此形状。返回仅`{"context": "..."}`或delegated时None。

管理员engine_root有效时，context附加renderer与SKILL的绝对路径，避免业务cwd误找相对tools路径。新增验证同时覆盖无agentcore安装的引擎加载与绝对路径提示；上下文提醒产物不要暴露内部安装路径。

精确启用脚本见插件README。无生产变更、无提交。后续更改由主agent统一收口。
