## D1 —— T4 带图文档（派前沿模型）

**目标**：修现有渲染链路，交付**实际渲染结果**（PNG + HTML），不新建第二套渲染工具。

**指导**：`docs/reports/2026-10-26_delivery.md` 的「T4」一节。

**范围（按该文件「最小实施顺序」）**：
1. 修新鲜度与旧产物误报：`--png-only` 不得在 Markdown 变更后复用旧 HTML；为「改源文后第二次 `--png-only`」「旧 PNG + 浏览器失败」建立回归。
2. 加自动高度与渲染结束检查：按正文实测高度截图，超限拆图或**明确失败**；长文末尾哨兵验证不截断。
3. 修浏览器发现顺序（环境变量 → PATH → 当前用户目录）与图块统计口径（与 `mermaid_to_div()` 共用解析规则）。
4. 隔离目录生成一份含代码 / 表格 / 时序图 / 多分支图的样例，跑 `verify_render.sh`，**看 PNG 校样**。
5. 从日常对话触发同一技能，确认交付真的含 PNG + HTML——**只有这一步过了才能标「日常路径接通」**。

**交付**：改动文件 + 回归测试 + 样例产物路径 + 校样结论。
**不做**：不引入 D2 / Kroki / Marp；不新增外部渲染服务。

## D2 —— T8 能力漂移告警（派前沿模型）

**目标**：在既有巡检结果与发送器之间接**持久 outbox**，不新增第二套能力基线表。

**指导**：`docs/reports/2026-10-26_ops_learning.md` 的「T8」一节。

**范围**：
1. 每个 profile/scope 保存漂移 **episode**；同 episode 不重复建消息，健康观测结束 episode。
2. **单事务**写 episode 与 outbox；消息带稳定 `event_id`。
3. 发送器以**租约**认领，成功确认后标 sent；超时租约可重领，旧 worker 不能确认新租约。
4. 记录检测值 / 期望值 / 是否已落盘修复 / 运行时是否已加载——**别把「写入配置」称成「已生效」**。
5. 渠道不支持幂等键时，**承认发送确认不明窗口**，不承诺绝对只发一次。

**验收（逐条实测）**：正常周期零消息；压低白名单能力值后恢复**并发一条**告警；连续两轮不刷屏；恢复后再次压低可**再**告警；发送失败或 worker 崩溃后事件**不丢**；并发发送器只认领一个租约。
**不做**：真实通知需用户指定目标并实测——**本轮不发**。

**验收**：新环境 clone 后单一自检命令退出 0；报告列明网关消息收发、模型凭据、生产记忆迁移**仍需单独验收**。

## D4 —— T9 自学习前半段（派前沿模型）

**目标**：定时检索 → 保存来源 → 提炼到**候选区**；**先不自动写正式记忆**。

**指导**：`docs/reports/2026-10-26_ops_learning.md` 的「T9」一节。

**范围**：
1. 由 T2 worker 领取**受预算控制**的检索任务；调度器不持有浏览器与模型执行上下文。
2. 抓取结果保留时间与来源；候选引文必须能在来源快照中**逐字定位**，失败即拒绝。
3. 候选与正式记忆**分库**：候选不参与默认召回；来源缺失 / 冲突未解 / 证据不足**不能自动 approve**。
4. 候选字段至少含：`candidate_id / statement / literal_quote / source_url / source_hash / retrieved_at / domain-scope / review_status / reviewer / reviewed_at`。
5. URL 与原文按**不可信数据**处理，不能变成工具指令。

**验收**：测试来源含明确事实时形成**可追溯候选**；伪造引文**拒绝**；来源重复不重复入库；待审候选**不进入**正式召回。
**不做**：本轮不接自动入库、不接真实渠道。
