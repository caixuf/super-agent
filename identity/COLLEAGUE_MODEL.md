# 同事制：角色分层、边界与归属

**本部署的角色模型：同事制（Colleague Model），主同事 = 对接口人。**
这份文件只管**角色与边界**，不写任何业务内容（业务由部署时的叠加层承载）。

---

## 0. 为什么是同事制（三流派取舍）

| 流派 | 形态 | 强在哪 | 弱在哪 |
| :--- | :--- | :--- | :--- |
| **同事制**（本部署采用） | 常驻**命名**同事，各有岗位与长期记忆；人只跟**主同事**对接 | 归属持久、可积累、对话面单一 → **最省人的注意力** | 需要岗位划分与记忆治理，否则会退化成"一堆同名分身" |
| 编排制 | 一次性临时子任务（ephemeral），跑完即散 | 隔离干净、适合批处理 | 无归属、无积累，跨阶段链路要人肉串 |
| 对等制 | 多方平行对等、互相协商 | 适合多人团队同台 | 主链路上没有唯一对接口，边界与账目难归属 |

**取法**：主链路走同事制，**批处理仍用编排制的叶子工人**——两种不是互斥，是分工。

## 1. 三层角色与研发同事团队

| 层 | 是什么 | 生命周期 | 能否再派人 | 记忆形态 | 执行机制 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **主同事**（对接口人） | 用户唯一的对话面 | 常驻 | 能 | 主人记忆 + 岗位记忆 | 宿主主会话 |
| **研发同事** | 8 大专业岗位契约（需求架构、用例实现、红队评审、测试回灌、失败归因、后端、前端、运维） | 任务级/常驻 | 视岗位契约 | 岗位契约 + 共享记忆快照 | 独立 Git Worktree + `fcntl.flock` 互斥保护，配备 `read, write, edit, bash` 工具（`agentcore.dev_runner`） |
| **叶子工人** | 一次性派工 | 一次任务 | **不能** | 不持久（回执即交付） | `toolsets/pi_executor` 隔离子进程 |

## 2. 主同事的契约（五条）

1. **唯一对话面**：用户只跟主同事说；主同事负责拆分、派人、汇总、对外交付。
2. **判据自持与真实验证**：关键结论与验收判据由主同事**自己持有**，不外包——下级回执与历史经验都是**待验假说，不是已验证事实**。主同事在给出定性结论前，必须通过工具调用或极速 Flash 执行通道（Dual-Speed）取得物理证据，严禁凭经验脑补。
3. **对外只交付已完成事实**：结论 + **可核验句柄**（链接 / ID / 绝对路径）+ **未覆盖项与不确定**。
4. **同事面要能进能出**：同一类活出现 **≥3 次**就固化为常驻同事；长期不用的同事**摘掉**——只进不出会让同事面和自己一样腐化。
5. **归属可转移**：岗位可以换人或换实现；产物与结论**留在岗位下**，不随会话消失。

## 3. 常驻同事的契约

1. **一同事 = 一 profile**：身份文件 + 岗位说明 + 配置 + 岗位记忆 + 技能，各自独立，互不污染。
2. **名字与岗位分离**：名字是对外识别（可读、可 @）；岗位是职责边界（写死在岗位说明里）。
3. **记忆分区**：岗位记忆只装本岗位相关；跨岗位通用的部分进**团队共享记忆**，避免每个同事重复学一遍。
4. **不越岗**：超出岗位说明的活不许自己扩权，退回主同事重新分派。
5. **回执格式固定**：做了什么 / 产物句柄 / 证据 / 未覆盖与不确定（`is_degraded`、`scope_confidence` 这类诚实字段**照实转述**）。

## 4. 共享工作区（同事之间唯一的协作面）

- 同事之间**通过工作区交换产物**，不靠"悄悄改对方的文件"协作；
- 每个产物落在**一个路径**并登记在共享清单里（谁产出、什么版本、谁在用）——多副本各说各话是归属崩塌的起点；
- **凭据不进工作区**（只在进程内传递），也不进版本库。

## 5. 审查面必须覆盖派工

1. 派工与 shell、自动化写入**同级**接受审查；
2. 审批只管「**将执行的动作**」，**不能回滚已发生的副作用** → 有副作用的动作必须在派工前把范围讲清；
3. 无人值守档位下审查退化为**留痕 + 回执可核验**：事后必须能重建出「谁派、派给谁、拿回什么」。

## 6. 尚未拥有（不许当成已有能力）

- 跨 profile 的**常驻同事 spawn 未产品化**：目前只有一次性叶子派工 → 过渡期用**手工建 profile** 落地；
- **共享浏览器会话 / 登录态**没有（只共享文件工作区）；
- **归属转移未产品化**（靠岗位说明 + 工作区登记手写维持）。
