# {{BUSINESS_OVERLAY_TITLE}} — 领域专家认知装甲与因果律模板

本文件是用于挂载到 `<business-profile>` 宿主身份中的领域专家叠加层模板。
部署时由宿主安装脚本装配，作为业务仓特定领域的硬核因果律防线。

## 1. 关键制动与退出机制门限
- **因果律**：在特定代际（如 `<vehicle-platform>`）下，退出条件通常包含力矩/行程越过底层门限（如 `<safety-critical-threshold>`）。
- **执行准则**：用例编写或退出测试中，必须注入对应档位（如 `brake.level=2` 或满足门限的强信号），否则状态机条件无法翻转导致超时。

## 2. 通信报文强类型约束
- **因果律**：底层序列化协议具有严格的强类型校验。
- **执行准则**：标量与整型字段（如 `<speed-signal>`）底层为 uint/int，严禁注入浮点数，必须传入合法整型数值。

## 3. 短脉冲与虚拟时间 (Sim-Time) 脱窗保护
- **因果律**：仿真环境由离散时间步推进，短脉冲信号（如按钮短按、脉冲触发）周期短。
- **执行准则**：严禁在短脉冲信号保持周期内插入阻塞休眠操作，否则会导致虚拟时钟跳变引发丢帧脱窗。

## 4. 5 模式测试点与两级评级联动
- **执行准则**：测试用例拆解必须遵循 5 模式全覆盖：
  - Mode 1: 正常激活与工作流保持（与核心 RP 清单 High 级严格联动，输出 P1 级正例）；
  - Mode 2: 边界抑制与前置条件不满足（与 Critical 级联动，输出 P2/P3 级反例）；
  - Mode 3: 退出与接管机制（制动接管、转向接管、超时退出）；
  - Mode 4: 阈值边界与去抖时序；
  - Mode 5: 状态机逆向跳变与死锁预防。

## 5. 单一事实源与制品校验
- 需求与用例以 `<business-repo>` 为唯一真值来源，平台仓不保留副本；
- 仿真产物必须校验 SHA256，严禁静默回退旧版本。
