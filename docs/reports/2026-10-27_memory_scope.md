# 本轮要求不能变成永久记忆

一次正式召回评测发现，“请直接回答，不调用工具”被自动存成了长期回答偏好，连寒暄也会召回它。逐字引文是真的，但适用范围错了。只检查是否来自用户原话，并不能保证记忆可靠。

自动路径现在先用用户自己的话判断是否有决策信号；助手在回答中说“必须”，不能让用户的问题自动变成已确认决策。提取出的引文还要保留疑问、否认与时间范围。本轮的工具、执行和改文件约束默认不升级为长期规则；明确的以后、默认、职责或个人偏好仍可入库。被否认的外部建议也不能当成用户已经采纳的方案。

管理员还可为独立记忆消费服务设置 `--exclude-session-prefix <private-probe-prefix>`，可重复指定。它只排除长期事实写入，先检查事件身份，不给被排除会话增加任何权限。原始回合仍保留审计记录，不靠删除测试记录掩盖误写。

消费日志新增事件键的 SHA-256、结果代码与写入条数，能核对为什么某轮没有写事实。日志不记录消息正文、提取结果或原始事件键。

专项覆盖用户提问与助手决策混淆、本轮限制、长期偏好、被否认的建议、截去问号的引文，以及测试命名空间与身份检查。现场还用了真实抽取模型的 14 组样例；嵌入是隔离测试向量，不能据此声称生产向量召回质量通过。

已污染的那条记忆按事实库 API 标为 deprecated，保留原文和来源。之后正式召回的误命中归零，但尾延迟仍超过原门限；失败记录没有改成通过。本次解决的是这类适用范围误写，整体记忆质量与性能仍须持续评测。
