# 用 flash 提取记忆候选：本机进展

`agentcore.memory.memory_trigger.propose_facts` 接收用户和助手的单轮文本，以及由宿主提供的模型调用函数。可传入 `agentcore.ccp_analysis_model.model`，由 CCP 的 `flash` 路由处理；代码不指定具体底层模型。

接口先复用已有预筛，再要求每条候选引用用户原话，剔除明显的本轮限制和未确认表达。返回的是待审核候选，不调用记忆写入函数、不改变记忆库。原话匹配只能证明来源存在，不能证明它是长期事实，也不能替代语义核验、去重和冲突检查。

隔离测试覆盖无写入、引用不存在、模型失败、提问、本轮限制和未完成回合。一次本机 CCP `flash` 合成样例返回 1 条带用户原话的候选；该样例没有使用真实对话或修改记忆库。

当前尚未接到运行中的 memory worker，也没有评测集证明抽取的召回率和误命中率。现有 `memory_trigger.run` 仍是另一条可能写入的路径；不要将新增接口误认为已替换或自动约束它。接入前需要明确候选的持久化、审核和与现有队列的去重关系，并在隔离 profile 验证。
