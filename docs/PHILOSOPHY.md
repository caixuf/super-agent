# Super Agent 工程与稳定性哲学 (Engineering Philosophy)

> 优秀的智能体系统之所以稳定，从来不是因为往主干上堆叠了多少概念，而是因为**主干极简、接缝实证、故障显式、终态收敛、中断可续**。
> 本文件是仓库的最高工程准则。任何新特性、补丁或重构一旦与以下五条铁律冲突，一律以本准则为准。

---

## 一、主干极简与真机接缝实证 (Spine Over Subsystems)

1. **接缝即故障高发区**：单元模块各自 Mock 跑出 100% 通过率毫无意义。真正的生产事故几乎全部发生在跨层接缝处（`Pool -> Supervisor -> Sandbox -> Engine -> Transport -> IM Platform`）。
2. **真机跑通才算存在**：任何涉及沙箱挂载、进程信号、外部 CLI 协议或平台消息投递的改动，必须在真实宿主机链路上走完一次端到端闭环（真实命令、真实锁文件、真实落盘与回执），绝不接受“纸面推演应该能跑”。
3. **做减法优于叠补丁**：能用一套状态机表达的生命周期，绝不拆成四张互相同步的表；能复用既有协议（如 `EX_TEMPFAIL=75`）解决的恢复语义，绝不另起炉灶发明新字段。

---

## 二、显式暴露，严禁粉饰降级 (Fail-Visible, Never Mask Degradation)

1. **兜底是为了保用户交付，不是为了藏系统故障**：主引擎失败后切换备选引擎（如 `Hermes -> Pi`），或卡片更新失败后退回纯文本投递，属于**有损降级（Degraded Delivery）**，绝不等于“系统健康”。
2. **保留第一现场证据**：任何主路径失败触发降级时，必须在工单回执中完整保留主路径的退出码与关键错误摘要（`primary_error` / `primary_stderr`），严禁只留一句笼统的 `turn_failed` 把根因吞没。
3. **体检必须观测真实退化率**：运维诊断工具（`superagent.py doctor`）不仅检查静态文件哈希与进程存活，还必须观测最近任务的**主引擎降级率**与**未决死信计数**。主链路持续降级必须亮黄/红灯，绝不允许顶着 `ready` 绿灯静默裸奔。

---

## 三、单一终态真相，有界收敛 (Bounded Convergence)

1. **严禁无限期中间态**：任何异步状态机（工单执行、流式进度卡片、完工消息投递）中的中间状态（`pending`、`sending`、`unknown`、`parked`）都必须具备明确的收敛出口或退避上限。
2. **UI 视图让位于业务终态**：交互式卡片（Card）只是过程可视化的增强层，完工结论送达用户才是核心契约。当完工消息已确认送达（`acknowledged=1`）或终态卡片重试达到上限（如 3 次）时，卡片状态必须确定性地收敛至终态（`sent` / `degraded` / `retired`），严禁因卡片补丁超时而留下永久刷屏报警的僵尸记录。
3. **非会话探针自动归档**：本地 CLI 或运维探针产生的非聊天通道回执，不得混入面向人类会话的待投递死信队列制造告警疲劳。

---

## 四、生命周期可中断可续 (Interruptible & Drainable by Design)

1. **重启与超时是常态而非异常**：服务发版（`update`）、守护进程重启（`SIGTERM`）与网络瞬断随时可能发生，系统必须默认“任何在途任务都可能收到中断信号”。
2. **停服阶段严禁盲目拉起备胎**：执行器收到 `SIGTERM` / `SIGINT`（或子进程因 `-15` / `143` 退出）时，代表宿主正在停机排空，**严禁将其误判为业务失败去拉起备选引擎陪葬**；必须立即保存跨尝试持久化的检查点（Job-scoped Checkpoint），并以临时中断码（`EX_TEMPFAIL=75`）退出，交由队列无损重排。
3. **发版前先看在途负载**：部署工具停服前应探测在途运行工单，给予合理的自然排空窗口，最大限度避免腰斩长耗时任务。

---

## 五、轻重分流，能力配称 (Right Tool, Right Tier)

1. **秒级直答不入重队列**：时间换算、已知配置、仓库地址、以及“当前任务跑到哪了”这类状态查询，必须由前台直接回答或通过轻量状态查询接口（支持免 ID 列出当前会话近期工单的 `durable_status`）秒级返回，严禁派发重型异步研发工单或套娃查单。
2. **复杂推理配强模型，任务意图优先于默认兜底**：显式指定的任务级模型档位优先于 Worker 环境变量的静态低档兜底；架构设计、跨模块排障与代码维护等高复杂度任务必须匹配具备足够推理深度的模型档位，杜绝“小马拉大车”导致的死循环与半途而废。
